# Turkey Trot Review: Solving Quadratics

A Thanksgiving-themed, game-show style review for Algebra 2C, Unit 2: Solving Quadratics. Play solo or in teams, pick a dish and a point value, and answer the question.

## How to play

Open `index.html` in any web browser. No install or build step needed.

- Choose a category and point value from the board.
- Teams take turns. Miss a question and another team can steal it for half the points.
- Hints are available for half credit.
- Sound can be toggled on or off.

## Categories

- **Mashed Potato Multiplying**: simplify
- **Stuffing Factoring**: factor completely
- **Corny Solving**: solve by factoring
- **Radical Rolls**: simplify radicals
- **Pumpkin Patch Roots**: solve with square roots
- **Pie Formula**: quadratic formula

Questions are randomly generated, so each game is different.

## Hosting with GitHub Pages

In the repository's **Settings → Pages**, set the source to deploy from the `main` branch's root folder. The game will be served at `https://jwalker-pinkerton.github.io/turkey-trot-review-unit-3-test-review-/`.
